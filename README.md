# ChugGate

Performance-aware adaptive gate and multiband noise-control system for electric guitar and bass.

## Build Prerequisites

- CMake ≥3.22
- C++20 compatible compiler
- JUCE submodule (initialize via `git submodule update --init --recursive`)

## Build Instructions

To build the project, run the provided build script:
```bash
./scripts/build_all.sh
```

## Project Structure

- Factory presets are located under `Resources/Presets/`.
